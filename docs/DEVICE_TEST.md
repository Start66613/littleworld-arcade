# 实板验收清单（刷机后执行）

刷机前必须已完成：整片备份 + 备份校验 + 用户对这一次写入的明确许可。
本清单区分“代理能自动确认的”和“需要用户看屏幕/触摸确认的”。

## 0. 刷机命令（仅记录，未获许可前不执行）

```powershell
# 需要授权后才会运行；端口以当时枚举为准
. .\tools\activate_env.ps1
cd firmware
python "$env:IDF_PATH\tools\idf.py" -B D:\LittleWorld-Arcade\build -p COM5 -b 921600 flash
```

写入范围：

| 区域 | 偏移 | 文件 |
|---|---|---|
| bootloader | `0x2000` | `build/bootloader/bootloader.bin`（22,016 B） |
| 分区表 | `0x8000` | `build/partition_table/partition-table.bin` |
| 应用 | `0x10000` | `build/little_world_arcade.bin`（约 0.91 MiB，具体哈希见 `reports/BUILD_REPORT.md`） |

不写 C6、不动 eFuse、不整片擦除。

## 1. 代理可自动确认（串口日志）

- [ ] 串口出现 `ESP-ROM:esp32p4-...` 或正常 `boot:` 日志，无 `invalid header` / `Image requires chip rev` 报错
- [ ] `app_main` 打印 `Little World Arcade UI started (1024x600)`
- [ ] 没有 `Guru Meditation`、`abort()`、`StoreProhibited`、看门狗复位
- [ ] 连续 60 秒无重启（monitor 日志不重新出现 ROM 头）

## 2. 需要用户确认（屏幕）

- [ ] 开机后出现米色/淡紫渐变的 **Little World Arcade** 主页
- [ ] 标题、三张卡片、中文没有方框/乱码
- [ ] 三张卡片显示 “2048 / 贪吃蛇 / 打砖块”，有最高分
- [ ] 右上角喇叭图标可点，点击后图标在“有声/静音”之间切换
- [ ] 点左下“开始游戏”区域能进入对应游戏

## 3. 触摸与玩法

**2048**
- [ ] 在棋盘上向上/下/左/右滑动，方块按方向移动并合并
- [ ] 得分增加，顶部“得分”同步
- [ ] 合出 2048 时弹出“通关啦”，可选“继续游戏”
- [ ] 无路可走时弹出“游戏结束”，显示本局得分与最高分

**贪吃蛇**
- [ ] 滑动屏幕可以转向；右上角四个方向键也能转向
- [ ] 吃到食物后身体变长、分数 +10、速度变快
- [ ] 撞墙或撞到自己 → “游戏结束”

**打砖块**
- [ ] 手指在屏幕上拖动，挡板跟随（不跳变、不丢手指）
- [ ] 轻触发球；球撞墙/挡板/砖块反弹正常
- [ ] 打掉砖块加分，砖块消失
- [ ] 掉球扣一条命（顶部“生命”变化），3 条命用完 → “游戏结束”

**通用**
- [ ] 右上角暂停键 → “已暂停”，选“继续游戏”恢复
- [ ] “重新开始”清零分数重新开局
- [ ] 左上角返回箭头回到主页
- [ ] 主页上右上角齿轮 → “运行状态”页能打开并显示 tick rate / 内存，点“关闭”退出

## 4. 稳定性

- [ ] 连续进出三款游戏各 5 次（共 15 次以上），不卡死、不闪屏、不重启
- [ ] 每次回到主页再进“运行状态”，内部空闲堆没有持续下降（允许小幅波动）
- [ ] LVGL tick rate 在游戏内保持接近 50 /s（允许短暂波动）
- [ ] 长按/快速滑动不会误触发返回主页
- [ ] 断电重启后，最高分仍在（NVS 生效）
